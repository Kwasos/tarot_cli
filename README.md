# tarot_cli
A CLI for selecting Tarot cards.
Cards data in tarot.json is originally from https://github.com/metabismuth/tarot-json

## Usage
While in project folder:

`python3 main.py`

## Instalation
`git clone https://github.com/Kwasos/tarot_cli`

`cd tarot_cli`
